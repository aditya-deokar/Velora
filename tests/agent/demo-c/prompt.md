# Demo C — Starting Prompt (launch film, Claude Code)

The prompt is `velora prompts show --id launch-film`, with the placeholders filled for the fixture
product. The agent had only the installed skills (`velora/SKILL.md` first) and `--help`.

> Read VELORA.md and run npx velora guide --json in this project, then start from the installed
> velora/SKILL.md and follow its intent router. Make a 30-second launch film for Fieldnote, aimed at
> analytics leads at small SaaS teams. The one message: every dashboard now writes its own weekly
> summary. Start from the launch-film-30s blueprint (velora new video --blueprint launch-film-30s --id
> launch --route /) and follow brief.md: Hook, Problem, Reveal, Proof, CTA. Replace each shot with
> this app's real components for the KPI cards, the reports chart and the Auto-summaries panel, end on
> the call to action "Start free", and keep a crisp motion personality. If there is music at
> assets/music.wav, run velora audio beats --write-markers and velora compose snap --to beats. Prove
> each shot with velora shot or velora frames --contact-sheet, read the PNGs, and fix what you see
> before rendering. Run velora review and velora check, render a draft (--quality draft), and wait for
> my review before the master render.
