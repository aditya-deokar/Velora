## Starting prompts

Copy one into your coding agent and replace each `<placeholder>`. `npx velora prompts ls` lists them all; `npx velora prompts show --id <id>` prints the full text.

- **Launch film (30 s)** (`launch-film`): A 30-second announcement film for a product launch, cut to music.
- **Feature drop (15 s)** (`feature-announcement`): A short video announcing one new feature.
- **Website hero loop** (`website-hero-loop`): A muted, seamless loop for the top of a landing page.
- **Vertical teaser (9:16)** (`vertical-teaser`): A vertical social teaser with captions, cut on the beat.
- **Make my dashboard cinematic** (`dashboard-cinematic`): One cinematic shot of an existing page or dashboard.

Start from the `velora` skill (`npx velora skills install --agent claude`) and follow its intent router.

## Work with Studio

Use `npx velora edit --scene <id>` for scene timing and `npx velora edit --composition <file>` for the cut. **Ask agent** copies the selection, playhead, recent edits and your intent.

Preview scene batches with `npx velora edit apply --scene <id> --ops ops.json --json` and composition batches with `npx velora compose edit --composition <file> --ops ops.json --json`. Write the reviewed diff with `--expect-sha <sha> --write`. If the file changed, read it again and generate a new diff.
